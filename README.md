# 中日青年人才发展协会 · 官方网站落地页

围绕「青年、人才、发展」三个主题设计的响应式动态落地页，使用 HTML、CSS 和原生 JavaScript，无需安装依赖或构建。

## 预览

### Windows：一次设置，之后双击打开

在仓库根目录运行一次：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\setup-local.ps1
```

设置成功后会打开网站，并创建：

- 桌面“青发协网站”：后台启动服务并打开网页；服务已运行时直接打开。
- 桌面“停止青发协网站”：停止由本启动脚本管理的服务。
- 当前用户的登录启动项“CJYTD Preview”：登录 Windows 后自动启动后台服务，不自动弹出浏览器。

地址仍是 http://127.0.0.1:8000/?v=18#youth 。首次设置后可关闭 PowerShell；之后无需手动打开命令窗口。使用 Windows 自带的 PowerShell 5.1 和 .NET 提供本地服务，无需安装 Python、Node.js 或其他运行环境，也无需管理员权限。脚本使用相对路径，支持中文及含空格的目录；请勿在设置后移动仓库。

所有 PowerShell 文件以 UTF-8 BOM 保存，兼容 Windows PowerShell 5.1。后台日志和进程记录保存在 `.preview/`，不提交 Git。若 8000 端口被其他服务占用，启动器会提示，不会关闭其他程序。已在运行且首页内容完全一致的旧预览可继续使用；停止脚本只管理它自己启动并记录的进程。

移除快捷方式、登录启动项并停止脚本管理的服务：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\setup-local.ps1 -Remove
```

已检查脚本编码、语法、HTTP 页面/图片读取、并发访问与启动/停止逻辑；Windows 原生后台窗口和快捷方式仍需在目标 Windows 电脑验证。

### 手动预览 / 其他系统

下载本仓库后，打开 `dist/index.html` 即可浏览。也可以在仓库根目录运行静态服务器（该方式需保持终端运行）：

```sh
python -m http.server 8000 --bind 127.0.0.1 --directory dist
```

然后访问 http://127.0.0.1:8000/ 。本地地址只在运行该服务的电脑上有效；Git 同步和线上发布是独立操作。

## 文件结构

- `start.ps1` / `stop.ps1`：后台启动与停止本地预览
- `setup-local.ps1`：一次性设置桌面快捷方式和登录启动项
- `preview-server.ps1`：基于 Windows 自带 .NET 的静态文件服务，只监听 127.0.0.1
- `dist/index.html`：页面结构与中文内容
- `dist/styles.css`：品牌样式、响应式布局与动效
- `dist/app.js`：主题切换、导航与需求摘要交互
- `dist/assets/`：协会 Logo、宣传册图片与联系二维码
- `DESIGN.md`：设计方向、交互说明和资料口径

## 主要体验

- 青年、人才、发展三个首屏主题，悬停预览；点击或Enter直接跳至相应板块
- 支持鼠标悬停、触控点选和键盘方向键切换
- 背景缓动、轻微视差、滚动进入、成果数字和阅读进度动效
- 提供暂停动效开关，并遵循系统减少动态效果偏好
- 青年活动与论坛、招聘会、圆桌交流与挂牌双创三个章节
- 17张照片集中在各章节文案旁：青年5张、人才6张、发展6张；名称叠放在图片内，青年末图跨列采用宽幅裁剪
- 加大的中英板块标签与三项横向图标分类；悬停预览、点击锁定，滑动指示线与照片高亮、放大联动
- 青年绿色、人才青色、发展协会深蓝，标签、图标和照片高亮统一主题色
- 电脑端照片整体放大20%，手机维持原有2.5%，分类操作保留全部照片并遵循暂停动效设置
- 底部邀请与联系方式按35:65分栏，流程依次点亮并自动循环；手机端上下排列
- 协会名称与三章标题加大，补充协会介绍，人才交流活动更新为300+，介绍区方向提示与成果数字自动循环，三个板块沿用原有图文排版，桌面高度统一为923px
- 在浏览器中生成、复制和下载合作需求摘要

需求摘要仅在浏览器本地整理，不会上传，也不代表已向协会提交。电话、地址和二维码采用协会最新确认的信息；日本电话为080-4576-1104，中国电话为+86 18629613381，二维码已替换为最新提供的图片。
