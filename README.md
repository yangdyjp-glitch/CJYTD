# 中日青年人才发展协会 · 官方网站落地页

围绕「青年、人才、发展」三个主题设计的响应式动态落地页，使用 HTML、CSS 和原生 JavaScript，无需安装依赖或构建。

## 预览

下载本仓库后，打开 `dist/index.html` 即可浏览。也可以在仓库根目录运行静态服务器：

```sh
python -m http.server 8000 --directory dist
```

然后访问 http://localhost:8000 。

## 文件结构

- `dist/index.html`：页面结构与中文内容
- `dist/styles.css`：品牌样式、响应式布局与动效
- `dist/app.js`：主题切换、导航与需求摘要交互
- `dist/assets/`：协会 Logo、宣传册图片与联系二维码
- `DESIGN.md`：设计方向、交互说明和资料口径

## 主要体验

- 青年、人才、发展三个首屏主题，联动背景、介绍与浏览入口
- 支持鼠标悬停、触控点选和键盘方向键切换
- 背景缓动、轻微视差、滚动进入、成果数字和阅读进度动效
- 提供暂停动效开关，并遵循系统减少动态效果偏好
- 青年活动与论坛、招聘会、圆桌交流与挂牌双创三个章节
- 17张照片集中在各章节文案旁：青年5张、人才6张、发展6张；4:3或16:9裁剪，名称叠放在图片内
- 加大的中英板块标签与三项横向图标分类；悬停预览、点击锁定，滑动指示线与照片高亮联动
- 分类操作保留全部照片，支持键盘与手机点按，并遵循暂停动效设置
- 电话、微信联系，以及在浏览器中生成、复制和下载合作需求摘要

需求摘要仅在浏览器本地整理，不会上传，也不代表已向协会提交。电话、地址和二维码采用协会确认的宣传册联系信息。

## 部署

将 `dist` 设置为静态站点的发布目录即可，无需构建命令。当前线上预览：https://cjytd-youth-exchange.phd-yang.chatgpt.site/ （访问权限沿用现有站点设置）。

## 素材

协会 Logo、活动原图与宣传册联系素材由协会提供，仅用于本网站展示；图片与品牌素材的权利归相应权利人所有。活动标题以提供的文件名为准。同一脱口秀活动选用一张照片。
